## 🚨 Symptoms of a Broken Guessing Game

Before you add another feature, check whether your game suffers from any of these classic symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Crashes on bad input | No validation | `try/except` |
| 🐌 Infinite loop | No attempt limit | Max attempts |
| 🧊 Boring gameplay | No hints | "Higher/Lower" |
| 🔥 Too easy | Fixed range | Difficulty |
| 📉 No replay | One-shot | Loop |
| 🔇 No scores | No storage | JSON file |

> **💡 Tip:** Always wrap `int(input())` in `try/except` — users type letters and symbols constantly.

## 🚀 First 5 Minutes — Minimal Working Example

The fastest way to a working game.

**Step 1 — Secret.** `random.randint(1, 100)`.

**Step 2 — Loop.** Ask for a guess.

**Step 3 — Compare.** Higher / lower.

**Step 4 — Count.** Track attempts.

**Step 5 — Win.** Print result.

> **💡 Tip:** Limit attempts before adding difficulty — an unlimited game teaches nothing about pacing.
